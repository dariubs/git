---
title: "برنچ‌ها"
weight: 12
---

برنچ‌ها شاخه‌های مختلفی را برای توسعه ایجاد می‌کنند. فرض کنید در حال توسعه یک اپلیکیشن هستید و قصد دارید نسخه‌ی آینده را همزمان با نسخه‌ی فعلی توسعه دهید. اضافه کردن تمام این تغییرات با هم ممکن است مسبب شلوغی روند توسعه و تداخل فایل‌های هم‌نام شود.

با استفاده از برنچ‌ها در گیت می‌توانید یک مسیر جدید برای توسعه‌ی هر ویژگی ایجاد کنید. در گیت به‌طور پیش‌فرض برنچ اصلی به‌نام `master` است.

برای ساختن یک برنچ جدید:

```bash
git branch نام‌برنچ
```

برای نمایش لیستی از برنچ‌ها:

```bash
git branch
```

برای رفتن به یک برنچ:

```bash
git checkout نام‌برنچ
```

برای حذف یک شاخه:

```bash
git branch -d نام‌برنچ
```

برای ساخت یک برنچ و رفتن به آن همزمان:

```bash
git checkout -b نام‌برنچ
```

برای پاک‌کردن برنچ مخزن ریموتی که قبلاً از مخزن محلی پاک کرده‌ایم:

```bash
git push origin :<branch-name>
```
