title: "برنچ‌ها"

برنچ‌ها شاخه‌های مختلفی برای توسعه ایجاد می‌کنند. فرض کنید در حال توسعه یک اپلیکیشن هستید و قصد دارید یک قابلیت جدید را بدون تأثیر روی کد اصلی آزمایش کنید. با استفاده از برنچ‌ها می‌توانید یک مسیر مجزا برای توسعه ایجاد کنید.

در گیت به‌طور پیش‌فرض برنچ اصلی `main` یا `master` نام دارد.

## ساختن برنچ

```bash
git branch نام‌برنچ
```

## نمایش لیست برنچ‌ها

برای نمایش برنچ‌های محلی:

```bash
git branch
```

برنچ فعلی با علامت `*` مشخص می‌شود.

برای نمایش برنچ‌های ریموت:

```bash
git branch -r
```

برای نمایش تمام برنچ‌ها (محلی و ریموت):

```bash
git branch -a
```

برای نمایش برنچ‌ها با آخرین کامیت:

```bash
git branch -v
```

## رفتن به یک برنچ

روش مدرن با دستور `switch`:

```bash
git switch نام‌برنچ
```

یا روش قدیمی‌تر با `checkout`:

```bash
git checkout نام‌برنچ
```

## ساختن برنچ و رفتن به آن همزمان

با دستور `switch`:

```bash
git switch -c نام‌برنچ
```

یا با دستور `checkout`:

```bash
git checkout -b نام‌برنچ
```

## تغییر نام برنچ

```bash
git branch -m نام‌قدیم نام‌جدید
```

برای تغییر نام برنچ فعلی:

```bash
git branch -m نام‌جدید
```

## حذف برنچ

برای حذف یک برنچ که merge شده:

```bash
git branch -d نام‌برنچ
```

برای حذف اجباری (حتی اگر merge نشده باشد):

```bash
git branch -D نام‌برنچ
```

## حذف برنچ ریموت

```bash
git push origin --delete نام‌برنچ
```

یا روش قدیمی:

```bash
git push origin :نام‌برنچ
```

## ارسال برنچ به ریموت

```bash
git push -u origin نام‌برنچ
```

گزینه‌ی `-u` برنچ محلی را به برنچ ریموت متصل می‌کند تا دفعات بعد فقط `git push` کافی باشد.
