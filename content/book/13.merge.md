---
title: "ترکیب برنچ‌ها"
weight: 13
---

در بخش قبل نحوه‌ی استفاده از برنچ‌ها گفته شد. حال اگر بخواهیم این شاخه‌های جدا را دوباره با شاخه‌ی اصلی ترکیب کنیم، باید از دستور `merge` استفاده کنیم:

```bash
git merge شاخه
```

با این دستور محتویات شاخه‌ی داده‌شده با شاخه‌ی فعلی ترکیب می‌شود.

در صورتی که بخواهیم تاریخچه‌ی کامیت‌های شاخه‌ی مورد نظر در شاخه‌ی اصلی وارد نشود، از گزینه‌ی `--squash` استفاده می‌کنیم:

```bash
git merge <branch_name> --squash
```

در صورتی که عملیات مرج را روی فایل مشخصی اشتباه انجام دادید، برای گرداندن به وضعیت اول:

```bash
git checkout -m <filename>
```
