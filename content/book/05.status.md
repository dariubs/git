---
title: "وضعیت مخزن"
weight: 5
---

یکی از اساسی‌ترین کارهایی که با گیت می‌کنیم بررسی و ثبت تغییرات ایجاد شده در فایل‌های متنی پروژه است.

هر زمان که تغییرات ثبت‌نشده‌ی پروژه را مایل بودید بررسی کنید، دستور زیر را وارد کنید:

```bash
git status
```

این دستور فایل‌هایی که تغییر داده‌اید را برای شما لیست می‌کند. تغییرات شامل: ویرایش یک فایل، اضافه کردن فایل جدید یا حذف یک فایل و همچنین فایل‌های استیج‌شده یا استیج‌نشده می‌شود.

برای نمایش وضعیت به‌صورت خلاصه از گزینه‌ی `-s` استفاده کنید:

```bash
git status -s
```
