---
title: "حذف فایل‌ها"
weight: 8
---

اگر پس از ثبت یک فایل آن فایل را حذف کنیم، برای اضافه کردن تغییرات فایل حذف‌شده، دیگر امکان استفاده از `add` را نداریم و باید با دستور `rm` آن فایل را حذف کنیم:

```bash
git rm فایل۱ فایل۲ فایل۳
```

دقت داشته باشید برخلاف دستور `add`، استفاده از `git rm .` تمام فایل‌های پروژه را حذف می‌کند؛ پس از آن استفاده نکنید. :)

اگر اشتباهاً فایل‌های زیادی را دستی پاک کردیم بدون اینکه از دستور `git rm` استفاده کنیم، می‌توانیم از دستور زیر استفاده کنیم:

```bash
git rm $(git ls-files --deleted)
```

اگر بین نام فایل‌های پاک‌شده نویسه‌ی فاصله وجود داشته باشد:

```bash
git ls-files --deleted -z | xargs -0 git rm
```
