معمولاً پروژه‌هایی که چندین نفر روی آن کار می‌کنند مخزن اصلی را در یک سرور قرار می‌دهند و افراد همه‌ی تغییرات را روی آن مخزن اضافه می‌کنند.

می‌توانید از سرویس‌های اینترنتی مانند گیت‌هاب، بیت‌باکت و بسیاری سرویس‌های دیگر استفاده کنید.

## remote

برای نمایش، اضافه و حذف کردن تغییرات در یک مخزن ریموت از دستور `remote` استفاده می‌شود.

برای نمایش لیستی از ریموت‌ها:

```bash
git remote
```

برای اضافه کردن یک مخزن ریموت:

```bash
git remote add [name] [url]
```

که به‌جای `[name]` یک نام برای ریموت مورد نظر و به‌جای `[url]` آدرس مخزن را قرار می‌دهیم.

برای حذف یک ریموت:

```bash
git remote rm [name]
```

## push

برای افزودن تغییرات کامیت‌شده به مخزن ریموت:

```bash
git push [remote-repo-name] [branch-name]
```

## pull

برای دریافت تغییرات از مخزن ریموت:

```bash
git pull [remote-repo-name]
```
