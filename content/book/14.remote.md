title: "استفاده از ریموت"

معمولاً پروژه‌هایی که چندین نفر روی آن کار می‌کنند مخزن اصلی را در یک سرور قرار می‌دهند و افراد همه‌ی تغییرات را روی آن مخزن ارسال و دریافت می‌کنند.

می‌توانید از سرویس‌های اینترنتی مانند گیت‌هاب، گیت‌لب، بیت‌باکت و سرویس‌های دیگر استفاده کنید.

## remote

برای نمایش، اضافه و حذف کردن مخازن ریموت از دستور `remote` استفاده می‌شود.

برای نمایش لیستی از ریموت‌ها:

```bash
git remote
```

برای نمایش آدرس ریموت‌ها:

```bash
git remote -v
```

برای اضافه کردن یک مخزن ریموت:

```bash
git remote add نام آدرس
```

برای مثال:

```bash
git remote add origin https://github.com/username/myproject.git
```

نام `origin` قراردادی است و به‌طور معمول برای مخزن اصلی استفاده می‌شود.

برای تغییر نام یک ریموت:

```bash
git remote rename نام‌قدیم نام‌جدید
```

برای حذف یک ریموت:

```bash
git remote rm نام
```

## fetch

دستور `fetch` آخرین اطلاعات را از مخزن ریموت دریافت می‌کند، اما آن‌ها را با برنچ فعلی شما ادغام **نمی‌کند**.

```bash
git fetch origin
```

برای fetch تمام ریموت‌ها:

```bash
git fetch --all
```

`fetch` برای بررسی تغییرات ریموت قبل از ادغام مفید است.

## pull

دستور `pull` از ریموت دریافت می‌کند و با برنچ فعلی ادغام می‌کند (ترکیب `fetch` و `merge`):

```bash
git pull origin نام‌برنچ
```

برای pull از ریموت پیش‌فرض:

```bash
git pull
```

## push

برای ارسال تغییرات کامیت‌شده به مخزن ریموت:

```bash
git push origin نام‌برنچ
```

برای اولین push یک برنچ و تنظیم ردیابی خودکار:

```bash
git push -u origin نام‌برنچ
```

بعد از این دستور، برای push های بعدی فقط `git push` کافی است.

## مشاهده‌ی اطلاعات ریموت

برای دیدن جزئیات یک ریموت خاص:

```bash
git remote show origin
```

این دستور اطلاعاتی مثل برنچ‌های ریموت و وضعیت ردیابی را نشان می‌دهد.
