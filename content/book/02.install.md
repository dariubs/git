## پیش‌نیازها

قبل از شروع کار با گیت لازم است مختصر آشنایی با دستورات خط فرمان در سیستم عامل خود داشته باشید. اگر از سیستم‌عامل‌های خانواده‌ی یونیکس (مثل لینوکس و macOS) استفاده می‌کنید و با محیط ترمینال آشنا نیستید، می‌توانید از ضمیمه‌ی ۱ کتاب استفاده کنید.

## نصب گیت

برای نصب گیت می‌توانید در وبگاه رسمی آن به صفحه‌ی دانلود بروید و نسخه‌ی سیستم‌عامل خود را دانلود و نصب کنید.

## نصب بر روی لینوکس

نصب گیت بر روی توزیع‌های مختلف لینوکس به شیوه‌های مختلف امکان‌پذیر است. متداول‌ترین روش، نصب از روی مدیربسته‌های توزیع مورد نظر است.

نصب بر روی دبیان و اوبونتو:

```bash
apt-get install git
```

نصب بر روی جنتو:

```bash
emerge --ask --verbose dev-vcs/git
```

نصب بر روی آرچ لینوکس:

```bash
pacman -S git
```

نصب بر روی اوپن‌زوزه:

```bash
zypper install git
```

نصب بر روی فدورا (تا نسخه‌ی ۲۱):

```bash
yum install git
```

نصب بر روی فدورا (نسخه‌ی ۲۲ و بالاتر):

```bash
dnf install git
```

## نصب بر روی macOS

نصب بر روی macOS با پکیج منیجر Homebrew:

```bash
brew install git
```

## نصب بر روی ویندوز

برای نصب گیت روی ویندوز، به صفحه‌ی دانلود گیت در وبگاه رسمی پروژه بروید و نسخه‌ی ۳۲ یا ۶۴ بیتی آن را، متناسب با معماری سیستم‌عامل خود دانلود و نصب کنید.
