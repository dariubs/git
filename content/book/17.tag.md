---
title: "تگ‌ها"
weight: 17
---

برای تگ‌زدن یک کامیت از دستور زیر استفاده کنید:

```bash
git tag -a v2.0 -m 'version v2.0'
```

برای ارسال همه‌ی تگ‌ها به مخزن از راه دور:

```bash
git push --tags
```

برای ارسال یک تگ مشخص:

```bash
git push origin <tag_name>
```

پاک‌کردن یک تگ از مخزن محلی:

```bash
git tag -d <tag_name>
```

پس از اینکه تگ محلی پاک شد، می‌توانیم تگ را از روی مخزن origin پاک کنیم:

```bash
git push origin :tagname
```
