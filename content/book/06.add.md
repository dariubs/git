---
title: "اضافه‌کردن فایل‌ها"
weight: 6
---

ثبت تغییرات در گیت بصورت معمول دو مرحله دارد:

1. اضافه کردن فایل‌های تغییر داده‌شده‌ی مورد نظر
2. ثبت تغییرات با یک پیام یا توضیح

برای اضافه‌کردن فایل‌ها به گیت از دستور `add` استفاده می‌کنیم:

```bash
git add فایل۱ فایل۲ فایل۳
```

و برای افزودن تمام فایل‌های تغییر داده‌شده:

```bash
git add -A
```

دستور `git status` که پیش‌تر توضیح داده شد، برای یافتن فایل‌های تغییر داده‌شده و اضافه کردن آن‌ها به شما کمک می‌کند.
