امروزه متداول‌ترین روش تعامل با سیستم‌عامل استفاده از واسط‌های گرافیکی است اما از ابتدای عصر کامپیوترهای دیجیتالی روش دیگری نیز بین کاربران متداول بود تحت عناوینی چون "محیط متنی" یا "واسط خط فرمان". نرم‌افزارهای این محیط در سیستم‌های عامل مختلف با نام‌هایی چون ترمینال، کنسول، cmd، tty و... خطاب می‌شوند.

در ترمینال‌ها دستوراتی تایپ و اجرا می‌شوند. بسیاری از کارهایی که در محیط‌های گرافیکی قابل انجام بودند اینجا هم به همان سادگی انجام می‌شود.

دو سری سیستم‌های عامل پرکاربرد را بررسی می‌کنیم:
- سیستم‌های عامل خانواده‌ی یونیکس (توزیع‌های لینوکس، macOS، خانواده BSD و ...)
- سیستم عامل ویندوز

## دستور `ls` — لیست

دستور `ls` را در ترمینال خود تایپ و اینتر کنید:

```bash
ls
```

لیست فایل‌های شما در فولدری که حاضر هستید نمایش داده می‌شود. توجه کنید که *bash به حروف کوچک و بزرگ حساس است*.

## دستور `mkdir` — ساختن دایرکتوری جدید

دستور `mkdir` برای ساختن دایرکتوری‌ها به کار می‌رود:

```bash
mkdir نام‌دایرکتوری
```

برای مثال:

```bash
mkdir project
```

## دستور `cd` — جابجایی بین دایرکتوری‌ها

برای رفتن به داخل دایرکتوری:

```bash
cd نام‌دایرکتوری
```

## فایل‌های مخفی

در سیستم‌های عامل شبه‌یونیکس، فایل‌هایی که با کاراکتر `.` (نقطه) شروع می‌شوند به‌صورت پیش‌فرض نمایش داده نمی‌شوند. برای نمایش فایل‌های مخفی با دستور `ls` از آپشن `-a` استفاده کنید:

```bash
ls -a
```

## صفحات راهنما

برای یافتن توضیحات و آپشن‌های هر دستور از صفحات راهنما استفاده کنید:

```bash
man نام‌دستور
```

برای مثال:

```bash
man ls
```

برای خروج از حالت نمایش صفحات راهنما، کلید `q` را فشار دهید.

## دستور `cd ..` — بازگشت به عقب

برای بازگشتن به دایرکتوری بالاتر:

```bash
cd ..
```

## دستور `pwd` — نمایش مسیر حاضر

```bash
pwd
```

## دستور `rm` — حذف

برای حذف یک فایل:

```bash
rm نام‌فایل
```

برای حذف یک دایرکتوری:

```bash
rm -r نام‌دایرکتوری
```

*توجه داشته باشید که حذف دایرکتوری به این روش خطرناک است و تمام محتویات دایرکتوری را برای همیشه حذف می‌کند.*
