بعد از نصب گیت لازم است تنظیماتی را انجام دهید و خودتان را به گیت معرفی کنید. این کار به‌خاطر ثبت تغییرات به نام شما و همچنین شخصی‌سازی گیت است.

تنظیمات گیت در سه سطح قابل انجام است:

- **سطح system:** تنظیمات روی مخازن تمام کاربرهای آن سیستم اعمال می‌شود. در `/etc/config` ذخیره می‌شود.
- **سطح global:** تنظیمات روی مخازن کاربر فعلی اعمال می‌شود. در `~/.gitconfig` ذخیره می‌شود.
- **سطح local:** تنظیمات تنها روی مخزنی که در آن قرار دارید اعمال می‌شود. در `.git/config` ذخیره می‌شود.

## تنظیمات اساسی

برای اضافه کردن نام خود:

```bash
git config --global user.name "نام شما"
```

برای ثبت ایمیل:

```bash
git config --global user.email آدرس@ایمیل.شما
```

توجه کنید که این تنظیمات اجباری است و در صورت عدم انجام آن‌ها در مراحل بعدی با مشکل مواجه می‌شوید.

برای تنظیم ویرایشگر پیش‌فرض:

```bash
git config --global core.editor ویرایشگر
```

برای مثال برای تنظیم ایمکس (Emacs):

```bash
git config --global core.editor emacs
```

برای مشاهده‌ی مقدار یک تنظیم خاص:

```bash
git config user.name
```

برای بررسی تمام تنظیمات:

```bash
git config --list
```

اگر مجبورید از پروتکل HTTPS استفاده کنید، می‌توانید نام کاربری و پسورد خود را کش کنید:

```bash
git config --global credential.helper cache
```

برای راهنمایی بیشتر:

```bash
man git-config
```

## alias ها

در گیت می‌توانید برای دستورات پرکاربرد نام‌های مستعار تعریف کنید؛ مثلاً بجای `git init` بنویسید `git i`.

برای ساخت alias:

```bash
git config --global alias.i init
```

## تنظیم گیت برای زبان فارسی

وقتی که پرونده‌های فارسی را به گیت اضافه می‌کنیم، گیت نام این پرونده‌ها را به درستی نمایش نمی‌دهد. برای رفع این مشکل:

```bash
git config --global core.quotepath false
```

## مطالعه بیشتر

صفحه‌ی راهنمای تنظیمات گیت را با دستور `man git-config` بخوانید.
