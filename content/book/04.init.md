---
title: "شروع یک پروژه با گیت"
weight: 4
---

دایرکتوری پروژه‌هایی که از سیستم‌های مدیریت کد منبع مثل گیت استفاده می‌کنند، با عنوان یک **repository** (در اصطلاح عامیانه ریپو، گاهی در فارسی مخزن) می‌خوانند.

دستور `git init` یک مخزن جدید گیت ایجاد می‌کند. با اجرای این دستور یک دایرکتوری با نام `.git/` درون دایرکتوری حاضر شما ایجاد می‌شود که حاوی فایل‌های کانفیگ و بلاب‌های تغییرات ثبت شده توسط گیت است.

برای اضافه کردن گیت به یک پروژه‌ی موجود، داخل دایرکتوری پروژه دستور زیر را وارد کنید:

```bash
git init
```

یا برای ساختن یک پروژه‌ی جدید:

```bash
git init نام‌دایرکتوری
```

که این دستور یک دایرکتوری با نامی که وارد کرده‌اید می‌سازد و گیت را به آن اضافه می‌کند.

وقتی که گیت به یک دایرکتوری اضافه می‌شود، در حقیقت یک دایرکتوری درون دایرکتوری پروژه به نام `.git` ساخته می‌شود که فایل‌هایی که سیستم گیت می‌سازد در آن قرار می‌گیرند. با این دستور پروژه‌ی شما به یک مخزن گیت تبدیل می‌شود.
