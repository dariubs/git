---
title: "کلون‌کردن یک مخزن"
weight: 5
---

علاوه بر ساختن یک مخزن جدید با `git init`، می‌توانید یک مخزن موجود را از اینترنت یا سرور دیگری روی سیستم خود دریافت کنید. این کار را **کلون‌کردن** می‌نامیم.

دستور `git clone` تمام تاریخچه‌ی کامیت‌ها، برنچ‌ها و فایل‌های یک مخزن را دانلود می‌کند.

## کلون ساده

```bash
git clone آدرس‌مخزن
```

این دستور مخزن را در یک دایرکتوری جدید با نام مخزن می‌سازد. برای مثال:

```bash
git clone https://github.com/torvalds/linux.git
```

## کلون در یک دایرکتوری مشخص

```bash
git clone آدرس‌مخزن نام‌دایرکتوری
```

برای مثال:

```bash
git clone https://github.com/torvalds/linux.git kernel
```

## کلون یک برنچ مشخص

به‌طور پیش‌فرض، کلون برنچ پیش‌فرض مخزن را دریافت می‌کند. برای کلون‌کردن یک برنچ خاص:

```bash
git clone -b نام‌برنچ آدرس‌مخزن
```

## کلون سطحی (Shallow Clone)

برای مخازن بزرگ که نیازی به تمام تاریخچه ندارید، می‌توانید فقط آخرین کامیت را دریافت کنید:

```bash
git clone --depth 1 آدرس‌مخزن
```

این کار سرعت دانلود را به‌طور چشمگیری افزایش می‌دهد.

## پروتکل‌های کلون

مخازن را می‌توان از طریق پروتکل‌های مختلف کلون کرد:

- **HTTPS:** `https://github.com/user/repo.git`
- **SSH:** `git@github.com:user/repo.git`
- **مسیر محلی:** `/home/user/projects/myrepo`

روش SSH برای توسعه‌دهندگانی که کلید SSH خود را در سرویس‌هایی مانند گیت‌هاب ثبت کرده‌اند توصیه می‌شود، زیرا نیازی به وارد کردن رمز عبور ندارد.
