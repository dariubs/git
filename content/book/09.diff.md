title: "مقایسه‌ی تغییرات"
weight: 9
---

برای بررسی تغییرات صورت گرفته در چند کامیت یا تغییرات کامیت‌نشده در مقابل تغییرات کامیت‌شده از دستور `diff` استفاده می‌کنیم.

حالت ساده‌ی استفاده:

```bash
git diff
```

که این دستور تغییرات کامیت‌نشده‌ی تمام فایل‌ها را به شما نشان می‌دهد. همچنین به‌صورت زیر می‌توانید تغییرات یک فایل خاص را نیز ببینید:

```bash
git diff نام‌فایل
```
