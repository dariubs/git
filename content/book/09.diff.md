برای بررسی تغییرات صورت گرفته در فایل‌ها از دستور `diff` استفاده می‌کنیم. این دستور خطوطی که حذف شده‌اند را با علامت `-` و خطوط جدید را با علامت `+` نشان می‌دهد.

## تغییرات ثبت‌نشده

```bash
git diff
```

این دستور تغییراتی را نشان می‌دهد که هنوز با `git add` استیج نشده‌اند.

برای تغییرات یک فایل خاص:

```bash
git diff نام‌فایل
```

## تغییرات استیج‌شده

برای دیدن تغییراتی که با `git add` استیج شده‌اند اما هنوز کامیت نشده‌اند:

```bash
git diff --staged
```

یا معادل آن:

```bash
git diff --cached
```

## تمام تغییرات ثبت‌نشده

برای دیدن تمام تغییرات (هم استیج‌شده هم استیج‌نشده) نسبت به آخرین کامیت:

```bash
git diff HEAD
```

## مقایسه‌ی دو برنچ

```bash
git diff برنچ۱ برنچ۲
```

برای مثال:

```bash
git diff main feature/login
```

## مقایسه‌ی دو کامیت

```bash
git diff هش‌کامیت‌اول هش‌کامیت‌دوم
```

یا با استفاده از مرجع‌های نسبی:

```bash
git diff HEAD~2 HEAD
```

این دستور تفاوت دو کامیت آخر را نشان می‌دهد.

## خلاصه‌ی تغییرات

برای نمایش تنها نام فایل‌های تغییریافته بدون جزئیات:

```bash
git diff --stat
```

## تغییرات بین یک کامیت و برنچ

برای مقایسه‌ی برنچ فعلی با یک برنچ دیگر از نقطه‌ی انشعاب:

```bash
git diff برنچ...
```

برای مثال برای دیدن تغییراتی که در برنچ feature اعمال شده نسبت به main:

```bash
git diff main...feature
```
